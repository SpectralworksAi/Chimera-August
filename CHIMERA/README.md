# CHIMERA Forge

## CHIMERA Cognitive Operating System Framework
**Current Release: 0.1 (Genesis Kit)**

CHIMERA is a continuity-oriented cognitive operating system and reasoning orchestration layer. It is not a conscious entity, but a structural protocol for maintaining reasoning stability, emotional clarity, and transferable cognitive state across models and tools.

### Core Architecture
- **docs/**: Specifications and guides.
- **runtime/**: CHIMERA Execution Runtime components.
- **core/**: Core stabilization and continuity engines.
- **hub/**: Agent and module routing.
- **registry/**: AI models and agents registry.
- **plugins/**: External tool bindings.
- **builders/**: Artifact and output compilation logic.
- **examples/**: Demonstration workflows.
- **tests/**: Architecture validation.
- **schemas/**: JSON/YAML schema definitions (e.g., PION packets).
- **prompts/**: Core instruction layers and modes (OON, OOFF, CCCC).
- **workflows/**: n8n and execution graphs.
- **ui/**: Front-end structures.
- **api/**: API contracts.
- **assets/**: Media and icons.
- **releases/**: Version snapshots.

### Prime Directive
Preserve useful continuity without creating false certainty. Continuity is the infrastructure. Everything else depends on it.
